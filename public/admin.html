⚡ Opsi 1: Vercel KV / Upstash Redis (Direkomendasikan - Paling Cepat & Gratis)
Database Redis serverless resmi Vercel. Pengaturan tersimpan secara instan (<20ms) dan permanen lintas seluruh serverless lambda global.
💡 Cara 1-Klik di Vercel Dashboard (Paling Mudah):
Buka Vercel Dashboard → Pilih Proyek Anda → Klik tab Storage → Klik Create Database → Pilih KV (atau Upstash Redis) → Klik Connect to Project.
Begitu terhubung, Bre AI akan otomatis mendeteksi database tanpa Anda perlu mengisi kolom URL & Token di bawah!

🐙 Opsi 2: Sinkronisasi Repositori GitHub (Auto-Commit dari Web)
Karena Anda deploy via Vercel + GitHub, setiap kali klik "Simpan", Bre AI langsung meng-commit config.json terbaru ke GitHub Anda!
💡 Cara Menggunakan GitHub Sync:
1. Buat Personal Access Token (PAT) di GitHub (Settings → Developer Settings → Personal access tokens → Token classic dengan izin repo).
2. Masukkan Token dan nama repositori (contoh: AmirunRayan/bre-ai-main).
3. Klik Test Koneksi GitHub lalu Simpan Semua Pengaturan.
